Java Operators and Precedence
The precedence order for most of Java Operators is not a key feature of exam questions , but it's good idea to have at least a passing familiarity with some of the key points, notably that multiplicative operators , multiply , divide and remainder in particular 	, **will be executed before** addition and subtraction.

| Postfix        | ++ --         |
| -------------- | ------------- |
| Prefix / unary | ++ -- + - ~ ! |
| Multiplicative | * / %         |
